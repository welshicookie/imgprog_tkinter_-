# 영상 처리 GUI 프로그램 (Image Processing GUI)

Python, Tkinter, OpenCV, NumPy를 활용하여 구현한 데스크톱 기반 영상 처리 프로그램입니다.

## 주요 특징

- 직관적인 파일 탐색기 연동 : .png, .jpg 이미지 파일 필터링 및 잘못된 확장자 선택 시 안내 메시지 출력
- 듀얼 뷰 비교 화면 : 좌측 원본 이미지와 우측 변환 이미지(결과)를 나란히 배치하여 실시간 변화 비교
- 동적 카테고리 및 세부 옵션 UI : 13개 주요 카테고리 선택 시 해당 기능의 세부 옵션 및 [뒤로가기] 버튼으로 화면 전환

## 지원 기능 (13개 카테고리)

회색 이미지 변환 : 기본 그레이스케일, 흑백 반전, 이진화 (임계값 127)
컬러 이미지 변환 : 빨강, 초록, 파랑, 컬러 (원본)
블러링 : 평균 블러링, 가우시안 블러링, 박스 필터 블러링
샤프닝 : 언샤프 마스크, 라플라시안 샤프닝, 강한 커스텀 샤프닝
에지 검출 : 소벨(Sobel), 라플라시안(Laplacian), 캐니(Canny)
필터링 : 최솟값 필터, 최댓값 필터, 미디언 필터, 주파수 저주파통과(LPF), 주파수 고주파통과(HPF)
모폴로지 : 침식(Erode), 팽창(Dilate), 열림(Open), 닫힘(Close)
확대/축소 : 0.5배 축소, 1.5배 확대, 2.0배 확대
보간법 : 최근접 이웃(Nearest), 양선형(Linear), 3차 회선(Cubic)
평행이동 : 오른쪽 이동 (+60px), 아래쪽 이동 (+60px), 대각선 이동 (+50, +50)
회전 : 90도 회전, 180도 회전, 270도 회전, 45도 회전
명암 대비 조절 : 밝기 증가 (+50), 밝기 감소 (-50), 대비 증가 (1.6배), 대비 감소 (0.5배), 히스토그램 평활화
합성 : 두 번째 이미지 선택 후 가중치 합성 (5:5, 7:3, 3:7)

## 설치 및 실행 방법

1. 필수 라이브러리 설치

    pip install opencv-python numpy pillow

2. 프로그램 실행

    python main.py
